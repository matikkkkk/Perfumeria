# Luxury Perfumería — React + Spring Boot + H2

Esta edición utiliza H2 persistente, sin servidor MySQL.

**Para arrancar en Windows:** abre PowerShell y ejecuta `./iniciar-perfumeria.ps1`. Requiere Java 21+, Maven y Node.js/npm.

- Frontend: http://localhost:5173
- Gateway: http://localhost:8080
- Catálogo: http://localhost:8081
- Usuarios: http://localhost:8082
- Órdenes: http://localhost:8083

**Lee `MIGRACION_H2.md` para detalles de persistencia, configuración y limitaciones.**
